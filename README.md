# 📊 Приложение для отслеживания котировок криптовалют Binance

Клиент-серверное приложение для отображения актуальных котировок криптовалют в реальном времени через WebSocket-соединение с биржей Binance.

## 🚀 Возможности

- Подключение к WebSocket-API Binance
- Трансляция котировок всем подключенным клиентам
- Отображение цен 8 криптовалют: BTC, ETH, LTC, BNB, XRP, ADA, DOGE, SOL
- Динамическое обновление цен в реальном времени
- Красивый и минималистичный интерфейс

## 🛠️ Технологии

- **Backend**: Node.js, WebSocket (библиотека ws)
- **Frontend**: HTML, CSS, Vanilla JavaScript
- **API**: Binance WebSocket Streams

## 📋 Требования

- Node.js (версия 14 или выше)
- npm (менеджер пакетов Node.js)

## 🔧 Установка и запуск
1. Установка зависимостей
bash
npm install
2. Запуск сервера
bash
node script.js
При успешном запуске вы увидите:

text
 WebSocket сервер запущен на порту 8080
 Подключено к Binance WebSocket
📊 Отслеживаем: btcusdt, ethusdt, ltcusdt, bnbusdt, xrpusdt, adausdt, dogeusdt, solusdt
3. Открытие клиента
Откройте файл index.html в браузере одним из способов:

Двойным кликом по файлу

Через Live Server в VS Code

Через любой локальный сервер

4. Использование
После открытия страницы:

Убедитесь, что статус изменился на " Подключено!"

Наблюдайте за обновлением котировок в реальном времени

Цены обновляются автоматически при каждом изменении на бирже

🐛 Возможные проблемы
Ошибка "Unexpected server response: 400"
Убедитесь, что сервер запущен (node script.js)

Проверьте, что порт 8080 свободен

Перезапустите сервер

Не отображаются котировки
Проверьте подключение к интернету

Убедитесь, что Binance API доступен

Проверьте консоль браузера на ошибки (F12)

WebSocket не подключается
Проверьте, что сервер запущен до открытия HTML

Убедитесь, что в коде указан правильный порт (8080)

Проверьте файрвол на вашем компьютере
